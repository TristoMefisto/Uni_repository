The bootstrap: a standard error from one data set

ISLR Figure 5.10, with a least squares slope (or a median) in place of the slide's α. 1000 data sets drawn from the true population give the real sampling distribution of the estimate; 1000 bootstrap samples drawn with replacement from a single data set try to reproduce it without ever seeing the population.

  1. Press Draw from the population: the gold histogram is the true sampling distribution, and its spread is the true SE (infeasible in practice).
  2. Press Bootstrap this data set: the blue histogram is built only from the n points on the left, resampled with replacement.
  3. Compare the spreads (histograms and boxplots): the bootstrap SE is close to the true one, also for the median, which has no simple SE formula. It is itself an estimate: press New original data set and bootstrap again to see it move.

The bootstrap replaces the population with the sample: drawing n observations with replacement from Z imitates drawing n observations from the population. It does not correct a bad estimate (the blue histogram is centred where Z happens to be), but it measures how much the estimate would move from sample to sample.

With errors that grow with x, the usual formula for the SE of the slope understates the true SE (it assumes a constant error variance). The bootstrap resamples the (x, y) pairs and does not need that assumption, so on average it gets closer to the true SE (over 40 original data sets of n = 100: true 0.174, bootstrap 0.171, formula 0.154).
